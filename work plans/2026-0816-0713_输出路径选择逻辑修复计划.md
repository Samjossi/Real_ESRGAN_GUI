# 输出路径选择逻辑修复计划（简化版）

> **状态**：待评审
> **范围**：`core/main.py`（输入/输出选择与任务组队的路径逻辑）；`task.py`、`param.py`、`define.py` 不动
> **时间**：2026-08-16 07:13（初稿），07:20 按用户意见改为简化方案 (UTC+8)
> **优先级**：中

---

## 1. 需求来源

用户反馈两点：

1. 点输出「浏览」时弹的是**保存文件**对话框，强制选/填文件名；而输出的本质是一个**目录地址**，逻辑错误。
2. 进一步要求简化交互：**砍掉拖放动作**，输入统一走「浏览打开文件对话框点选图片」，输出统一是「选一个文件夹」。

## 2. 现状分析（`core/main.py`）

- 输入浏览 `buttonInputPath_click`（`:520`）：`getOpenFileNames`，只能选文件；文件夹输入**仅能通过拖放**进入（`dropEvent` `:515`）。
- 输出浏览 `buttonOutputPath_click`（`:529`）：`getSaveFileName`，永远要求文件名。
- 输出语义随输入形态变化：文件夹输入时输出是目录（`os.walk` 分支 `:575-600` 中 `os.path.join(outputPath, ...)` 镜像目录结构）；文件输入时输出是与输入一一对应的文件路径（`|` 分隔）。
- 为支持「输出文件名自动带 ` (模型 倍率)` 后缀」，存在一套联动逻辑：`outputPathChanged` 标志 + `outputPathTraceCallback` + 6 个参数控件信号连接（`:394-401`），用户手动改过输出后联动断开。输出改为纯目录后，这套联动**整个失去存在意义**。

## 3. 改造方案（简化后）

### 3.1 交互模型

| | 修复前 | 修复后 |
|:---|:---|:---|
| 输入 | 浏览选文件 / 拖放文件或文件夹 | **仅浏览选文件（可多选）** |
| 输出 | 文件路径或目录，随输入形态变化 | **永远是一个目录**，文件名自动生成 |
| 参数联动 | `outputPathChanged` + trace 回调重算输出名 | **删除**（目录不随参数变） |

### 3.2 具体改动

1. **删除拖放**：`dragEnterEvent`、`dropEvent`、`setupWidgets` 末尾的 `setAcceptDrops` 相关代码（`:407-410`）全部移除。
2. **删除文件夹输入分支**：`buttonProcess_click` 中 `os.path.isdir(inputPath)` 的 `os.walk` 分支（`:575-600`）移除；输入只走单文件分支。
3. **输出框语义改为目录**：
   - `buttonOutputPath_click` 改为 `QFileDialog.getExistingDirectory`。
   - `setInputPath`：填输入框后，输出框**默认填第一个输入文件所在目录**（用户可再改）；不再生成带后缀的完整文件名。
   - `getOutputPath`/`outputPathTraceCallback`/`outputPathChanged` 及其信号连接全部删除。
4. **任务组队时生成输出文件名**（`buttonProcess_click`）：对每个输入文件，`输出 = 输出目录/基名 (模型 后缀).扩展名`。扩展名规则沿用现有逻辑：`.jpg/.tif/.tiff` 或自定义命令 → `.png`；开无损 WebP → `.webp`；有损模式 → `.webp`/`.jpg`。倍率后缀由当前 resize 参数生成（沿用 `getOutputPath` 里的 suffix 生成代码，搬入组队逻辑）。
5. **校验**：开始时检查输出框是已存在的目录（不存在则提示，或 `os.makedirs` 自动创建——倾向提示，避免用户打错路径时静默建目录）。
6. **命令行传图**（`sys.argv[1:]`）：仍支持，`setInputPath` 处理不变（只接受文件）。

### 3.3 明确不做

- 不保留任何形式的文件夹输入与拖放。
- 不保留单文件自定义输出文件名（用户已确认简化优先；文件名由程序生成）。
- 多文件同名冲突（不同目录下同名文件输出到同一目录会互相覆盖）：本次不处理，风险节注明。

## 5. 风险与注意点

- ⚠️ **同名覆盖**：不同目录下同名输入文件输出到同一目录会互相覆盖，且与「已存在输出文件是否覆盖」的现有行为一致（引擎直接覆盖）。本次不加去重。
- ⚠️ **输出目录默认与输入同目录**：处理结果会写到源图旁边。这是上游 GUI 的常见默认，用户可改；评审时如需改默认（如固定 `./output`）再调。
- ⚠️ 删除联动后，改倍率/模型不再刷新输出框——输出框是目录，无需刷新，这是预期行为而非回归。
- `config.ini` 不涉及输出路径持久化，无配置迁移问题。
