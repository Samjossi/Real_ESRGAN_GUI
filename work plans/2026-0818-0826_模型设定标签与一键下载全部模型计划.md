## 1. 需求来源

用户需求（原话整理）：

1. 新增一个「模型设定」标签页，把目前放在「高级设定」里的模型目录相关设置移过去，集中管理；
2. 增加「一键下载所有模型」按钮：一键下载，不要"下载了然后再选择"之类的多步操作，做傻瓜式设定。

## 3. 目标

- 标签栏新增「模型设定」页，顺序：基本设定 → **模型设定** → 高级设定 → 关于；
- 「模型设定」页收纳全部模型相关设置：模型目录（从高级设定原样移入）+ 模型安装状态 + 一键下载；
- 「一键下载全部模型」：一次点击下载 `MODEL_MANIFEST` 全部 6 个模型到当前模型目录，已存在且校验通过的自动跳过（补漏式），完成后自动重扫进模型下拉框，全程无需勾选；
- 下载中带进度条、当前文件名、可取消；下载中禁用目录切换与重复点击；
- 首启下载引导 `ModelDownloadDialog` 行为保持不变（它处理"完全没有模型"的场景），仅抽取共用下载逻辑，不做界面改动。

## 4. 设计要点

### 4.1 「模型设定」标签页布局

在 `setupWidgets()` 中新建 `frameModelConfig`（`QVBoxLayout`），从上到下：

1. **模型目录行**：从高级设定右栏原样移入——标签 + 只读 `entryModelDir` +「浏览…」+「重新扫描」；`buttonBrowseModelDir_click` / `rescanModels` / `modelDirWidgets` 逻辑不变，仅改父控件引用；
2. **模型状态行**：`labelModelStatus`，显示「已安装 X / 6 个模型」，在 `rescanModels()` 末尾统一刷新（启动、改目录、重扫、下载完成后自动更新）；状态判定 = 清单中 `name` 是否出现在 `scan_models` 结果里；
3. **一键下载区**：`buttonDownloadAllModels`（「一键下载全部模型」）+ `labelDownloadStatus`（当前文件名/完成提示）+ `progressBarDownload` + `buttonCancelDownload`（默认禁用）。进度控件平时收起显示，仅下载中可见（`setVisible` 控制），避免占位。

高级设定右栏移除模型目录行后，其余复选框整体上移，不新增内容。

### 4.2 一键下载逻辑

- 抽取共用批量下载函数到 `core/download.py`：`download_models(entries, destDir, progress_cb, cancel_event) -> list[str]`，内部维护 `zip_cache`、逐模型下载、收集错误信息、结束后清理 zip 缓存并返回错误列表；`ModelDownloadDialog` 与新标签页按钮共用，消除逻辑分叉（对话框内的内联 `run()` 改为调用它）；
- 新增 `model_verified(entry, dest_dir) -> bool`：逐文件比对 SHA-256，全部通过才算已安装；
- 点击按钮流程：取 `currentModelDir()` → 校验目录可写（复用对话框同款检查）→ 后台线程遍历清单，`model_verified` 通过则跳过并回调「已存在，跳过」→ 下载缺失项 → 完成后 UI 线程 `rescanModels()` 自动刷新模型下拉框并写日志；
- 完成提示：全部成功且无错误 → 日志 + 状态行「全部模型已就绪」；部分失败 → 弹警告列错误（复用对话框错误文案模式）；用户取消 → 状态行提示已取消，保留已下载部分；
- 互斥：下载中禁用 `buttonDownloadAllModels`、`modelDirWidgets`、取消按钮反向启用；`processing`（超分任务运行中）时同样禁用下载按钮，加入 `updateProcessButton()` 的统一管理。

### 4.3 持久化

不新增配置项：目录仍走 `ModelDir`，下载完成即走现有 `rescanModels()` 刷新，无需额外落盘动作（目录改动时已有 `saveConfig()`）。
