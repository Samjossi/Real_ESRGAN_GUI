# Tkinter 迁移 PySide6 工作计划

> **状态**：草稿
> **范围**：GUI 层整体迁移（`main.py`、打包配置、依赖清单）；`task.py`、`i18n.py`、`param.py`、`define.py` 原则上不动
> **时间**：2026-08-15 18:07（设计）(UTC+8)
> **优先级**：中

---

## 1. 背景与目标

当前 GUI 基于 Tkinter + ttk + Sun Valley 主题（`theme/sun-valley.tcl`）+ tkinterdnd2 实现。计划整体迁移至 PySide6（Qt），目标：

- 跨平台（Windows / Linux / macOS）获得更现代、更一致的界面观感与交互
- 原生支持高 DPI，移除 Windows 下 `ctypes` DPI 感知补丁
- 深色/浅色主题跟随系统的能力保留并简化
- **功能零回归**：现有全部功能（配置读写、多语言、拖拽、进度动画、任务栏进度、通知、日志）逐一对应保留

非目标：

- 不改动处理核心逻辑（`task.py` 的任务队列、子进程调用）
- 不改动配置格式（`config.ini` 字段保持兼容）
- 不改动 i18n 体系（`i18n.ini` / `i18n.py` / `generate_locales_map.py`）

## 2. 现状分析

### 2.1 GUI 耦合面

Tkinter 相关代码集中在 `main.py`（约 838 行），其余模块无 GUI 依赖：

| 模块 | GUI 耦合 | 迁移处理 |
|:---|:---|:---|
| `main.py` | 🔴 全部 | 整体重写为 PySide6 |
| `task.py` | 🟢 无（仅通过回调 `writeToOutput` 与 GUI 通信） | 不动 |
| `i18n.py` | 🟢 无 | 不动 |
| `param.py` | 🟢 无 | 不动 |
| `define.py` | 🟢 无 | 不动 |

### 2.2 控件映射表

| 现有（Tkinter） | 目标（PySide6） | 备注 |
|:---|:---|:---|
| `TkinterDnD.Tk` + `ttk.Frame(REGUIApp)` | `QMainWindow` / `QWidget` | 主窗口类重写 |
| `ttk.Notebook`（三个选项卡：基本/高级/关于） | `QTabWidget` | |
| `ttk.Entry` | `QLineEdit` | 输入/输出路径、自定义命令 |
| `ttk.Button` | `QPushButton` | `Accent.TButton` 样式用 QSS 或 `setDefault` 实现 |
| `ttk.Combobox`（readonly） | `QComboBox` | 模型、降采样、Tile 尺寸、语言 |
| `ttk.Spinbox` | `QSpinBox` | 缩放参数、GPU ID、有损质量 |
| `ttk.Radiobutton` | `QRadioButton` + `QButtonGroup` | 五种缩放模式 |
| `ttk.Checkbutton`（Switch 样式） | `QCheckBox` | 六个开关 |
| 自定义 `ScrolledText`（tk.Text + ttk.Scrollbar） | `QPlainTextEdit`（只读） | 原自定义类直接废弃 |
| `ttk.Progressbar` | `QProgressBar` | |
| `filedialog.askopenfilename` | `QFileDialog.getOpenFileNames` / `getSaveFileName` | 输出路径选择修正为"保存"语义 |
| `messagebox.showwarning/showerror` | `QMessageBox.warning/critical` | |

### 2.3 机制映射表

| 现有机制 | 迁移方案 | 风险 |
|:---|:---|:---|
| `tk.Variable` + `trace_add` 联动（输出路径自动重算） | Qt 信号/槽（`textChanged`、`currentIndexChanged`、`valueChanged`、`toggled`） | 🟢 低 |
| 工作线程直接回调 `writeToOutput`（Tk 下未做线程隔离） | 改为 `Signal(str)`，经队列连接投递到 GUI 线程 | 🟡 中：Qt 对跨线程操作界面对象严格，必须信号化 |
| 进度条缓动动画（`after` 定时器） | `QTimer` 复刻相同的三次方缓动 | 🟢 低 |
| 拖拽（tkinterdnd2 `DND_FILES` + Tcl 解析 `e.data`） | Qt 原生 `setAcceptDrops` + `dragEnterEvent`/`dropEvent`，从 `mimeData().urls()` 取路径 | 🟢 低：同时废弃 `dndSplit` 的 Tcl 解析 hack |
| 深色主题（`sun-valley.tcl` + darkdetect 监听线程） | 见 §3 决策点 D1 | 🟡 中：主题方案未定 |
| Windows 任务栏进度（comtypes `ITaskbarList3`，取 `wm_frame()` 句柄） | 保留 comtypes 逻辑，句柄改取 `int(window.winId())` | 🟡 中：需实测窗口句柄层级 |
| 桌面通知（notify-py） | 保持 notify-py 不变（见决策点 D2） | 🟢 低 |
| 窗口图标/居中/最小尺寸 | `setWindowIcon` / `QScreen.availableGeometry` / `setMinimumSize` | 🟢 低 |
| HiDPI 补丁（Windows `ctypes.windll.shcore`） | 删除，Qt6 默认启用高 DPI 缩放 | 🟢 低 |
| 启动时隐藏窗口再显示（`withdraw`/`deiconify`） | 按需用 `show()` 时机控制，或自然显示 | 🟢 低 |

### 2.4 打包与依赖

- `requirements.txt`：移除 `tkinterdnd2`，新增 `PySide6`（版本固定策略见决策点 D3）；主题方案若选第三方库则一并新增
- `realesrgan-gui.spec`、`realesrgan-gui-macos.spec`：PyInstaller 配置需更新——移除 `pyi-hooks/hook-tkinterdnd2.py` 的 hooks 引用，确认 PySide6 插件（platforms、styles）被正确收集；`theme/` 目录与 Tcl 文件按主题方案决定去留
- `pyi-hooks/hook-tkinterdnd2.py`：迁移完成后删除

## 3. 决策点（待审阅时确认）

| 编号 | 问题 | 备选方案 |
|:---|:---|:---|
| D1 | 深色/浅色主题方案 | A. `qdarktheme`（第三方，一行启用，接近 Sun Valley 观感）；B. 自维护 QSS（零新依赖，工作量大）；C. Qt 原生 Fusion + 调色板（最简单，观感一般） |
| D2 | 桌面通知 | A. 保持 notify-py（零改动，跨平台已验证）；B. 改用 `QSystemTrayIcon.showMessage`（减少依赖，macOS 行为不同需测试） |
| D3 | PySide6 版本约束 | A. `PySide6 == 6.*`（跟随大版本）；B. 锁定小版本（如 `== 6.9.*`，更可控） |
| D4 | 迁移方式 | A. 一次性重写 `main.py`（代码干净，期间无中间态）；B. 新建 `main_qt.py` 并行存在，验证后替换（可回退，短期双份维护） |

建议：D1 选 A、D2 选 A、D3 选 B、D4 选 A。最终以审阅意见为准。
