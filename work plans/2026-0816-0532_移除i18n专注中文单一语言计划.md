# 移除 i18n 专注中文单一语言计划

> **状态**：已实施并验证（2026-08-16，冒烟测试全部通过，见 `tmp/smoke_test.py`）
> **范围**：`main.py`、`i18n.py`、`i18n.ini`、`generate_locales_map.py`、`config.ini`、`requirements.txt`、两个 `.spec` 打包文件、README/CONTRIBUTING 文档；`task.py`、`param.py`、`define.py` 不动
> **时间**：2026-08-16 05:32（设计）(UTC+8)
> **优先级**：中

---

## 1. 需求来源

用户决定：去掉多语言 i18n 机制，项目只维护中文单一语言版本。GUI 文案从 i18n 键值查询改为直接硬编码中文，删除翻译基础设施。

---

## 2. 现状分析（已实地调查）

### 2.1 i18n 机制构成

- `i18n.py`（62 行）：模块加载时读 `i18n.ini`，提供 `getTranslatedString(key)`、`set_current_language()`、`locales_map` 等模块级 API；缺 key 时回退英语。`change_current_lang` 为无调用的死代码（Tkinter 时代遗留）。
- `i18n.ini`（452 行）：8 个 section / 14 个语言码（zh_CN、zh_TW、en_US、uk_UA、tr_TR、es_ES、fr_FR 等），每区约 53 个 key（es/uk 少 5 个，靠回退英语补齐）。
- `generate_locales_map.py`（41 行）：译者辅助工具，用 babel 生成语言显示名，不在运行时使用；`requirements.txt` 中 babel 仅为此服务。

### 2.2 使用面（集中在 `main.py`，约 107 处匹配）

- 47 处 `i18n.getTranslatedString(...)` 调用：`retranslateUi()`（main.py:432-482）约 40 处集中刷新 + 运行时警告/通知/状态约 7 处。
- 语言下拉框机制：`comboLanguage`（main.py:318-319、412、425）、`change_app_lang()`（main.py:502-504）、`retranslateUi()`。
- 配置读写：`AppLanguage` 写回（main.py:554）、启动读取（main.py:970）、默认值探测 `locale.getdefaultlocale()`（main.py:931）。
- `ITEM_STATE_LABEL_KEYS`（main.py:82-90）：状态→i18n key 映射，行状态在 main.py:812 取用。
- `import locale` 仅为默认语言探测服务。

### 2.3 其他影响面

- 打包：`realesrgan-gui.spec:8` 与 `realesrgan-gui-macos.spec:30` 均把 `i18n.ini` 打进 datas。
- 配置：`config.ini:22` 有 `applanguage = zh_CN`，旧配置文件会残留该键。
- 冒烟测试：`tmp/smoke_test.py` 不 import i18n，但断言硬编码中文文案（`'开始'`、`'正在停止'`，tmp/smoke_test.py:115,117），改造后断言需与新中文文案一致。
- 文档：`README.md:95-98` 多语言特性段落、`CONTRIBUTING.md:32-92,130-188` 「添加或改进翻译」整章、`README.en-US.md` / `README.tr-TR.md` / `README.uk-UA.md` 三份译文。
- `Info.plist:29-33` 的 `LSEnvironment.LANG=zh_CN.UTF-8` 无害，保留。
- `task.py`、`param.py`、`define.py` 零 i18n 引用，不动。

## 3. 改造方案

### 3.1 代码改造（`main.py`）

文案取值原则：一律采用 `i18n.ini` 中 `zh_CN` section 的现有文案作为硬编码值，保持用户可见文字不变。

1. **删除 `import i18n`、`import locale`** 及全部 `getTranslatedString` 调用，原位替换为对应中文字面量。
2. **删除 `retranslateUi()`**（main.py:432-482），其中约 40 处 setText/setTabText/addItem 改为在控件创建处直接设中文文本；注意其中混有非文案逻辑（如模型/放大倍率下拉框重建），需甄别保留。
3. **删除语言下拉框**：`comboLanguage` 的创建、填充（main.py:318-319）、`setCurrentIndex`（main.py:412）、信号连接（main.py:425）、`change_app_lang()`（main.py:502-504）；同步删除「语言」标签，调整所在布局。
4. **删除 `AppLanguage` 配置链路**：写回（main.py:554）、读取（main.py:970）、默认配置项（main.py:931）。对旧 `config.ini` 残留的 `applanguage` 键采取「忽略不删」策略（configparser 读取未知键无害），不主动改写用户配置。
5. **`ITEM_STATE_LABEL_KEYS`（main.py:82-90）改为直接映射中文字符串**，重命名为 `ITEM_STATE_LABELS`；main.py:812 取用逻辑相应简化。
6. 运行时文案（警告弹窗 main.py:606-668、完成/失败通知 main.py:724-735、停止提示 main.py:493、启动检查 main.py:981）原位替换中文。

### 3.2 删除文件

- `i18n.py`
- `i18n.ini`
- `generate_locales_map.py`

### 3.3 打包与依赖

- `realesrgan-gui.spec:8`、`realesrgan-gui-macos.spec:30`：删除 `('i18n.ini', '.')` datas 条目。
- `requirements.txt`：删除 babel 行（注释标注仅用于语言名生成）。

### 3.4 文档清理

- `README.md:95-98`：删除「多语言支持」特性段落；顺带检查 :219 等处表述。
- `CONTRIBUTING.md`：删除「添加或改进翻译」整章（32-92、130-188）及 generate_locales_map.py 使用说明。
- **待用户决策**：三份 README 译文（`README.en-US.md`、`README.tr-TR.md`、`README.uk-UA.md`）是否一并删除？倾向删除——单一中文语言项目不再维护译文；亦可保留作宣传材料但标注「可能过时」。

### 3.5 冒烟测试适配

- `tmp/smoke_test.py` 断言文案与新硬编码中文比对（现有断言 `'开始'`、`'正在停止'` 取自 zh_CN 文案，预期无需改动；实施后实跑确认）。

## 5. 风险与注意点

- `retranslateUi()` 删除是核心风险点：其中约 40 处文案必须逐条核对迁移，漏一条就是界面空白文本。
- 模型/放大倍率下拉框的重建逻辑若藏在 `retranslateUi()` 中，必须剥离保留，不能随函数一起删掉。
- 旧 `config.ini` 残留 `applanguage` 键无害，忽略即可，不做配置迁移代码。
- 启动时不再探测系统语言：非中文系统用户将直接看到中文界面（符合单一语言定位）。
- 改动集中在单文件 `main.py`，建议一次提交前用 git diff 全量自查。
