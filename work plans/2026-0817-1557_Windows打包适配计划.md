## 1. 需求来源

用户目标：把本程序打包成 Windows 应用程序，分发到 Windows 电脑上使用。

## 2. 现状核查（已读代码确认）

| 项 | 现状 |
|:--|:--|
| 代码平台适配 | ✅ 基本就绪：`core/define.py` 对 `os.name == 'nt'` 自动探测 `.exe`；`core/task.py` 用 `CREATE_NO_WINDOW` 隐藏子进程窗口；`core/main.py` 有 Win10+ 深色标题栏 DWM 调用；`define.py` 的 `sys._MEIPASS`/`sys.executable` 分支兼容 PyInstaller onefile/onedir |
| 打包配置 | ✅ `asset/packaging/realesrgan-gui.spec` 已含 win32 处理（排除 UCRT/`_multiprocessing`），并支持 `REGUI_ONEFILE` 环境变量切 onefile/onedir |
| 引擎二进制 | 🔴 `bin/` 里只有 Linux 版 `realesrgan-ncnn-vulkan`，Windows 无法运行，必须换官方 Windows 版 `realesrgan-ncnn-vulkan.exe` |
| 构建环境 | 🔴 本机是 Linux，PyInstaller 不支持交叉编译，产 Windows 包必须有 Windows 构建机（实体机/虚拟机）或 CI |
| 模型 | 🟡 打包是否内置模型待决策；建议不内置，配合模型下载计划首启拉取（减小包体 ~70 MB） |
| 配置写入位置 | ⚠️ `config.ini` 写在 exe 同级目录（`define.APP_PATH`）。若用户把程序放进 `Program Files` 等只读目录会写配置失败，需在分发说明中明确「解压到非系统盘普通目录使用」，或由下载引导把模型目录默认指向用户目录 |

## 3. 目标

- 产出 Windows 可用的分发包：`realesrgan-gui-windows-x64.zip`（onedir 便携版，解压即用）；
- 首次启动无模型时走模型下载引导（依赖前置计划），用户选择目录拉取模型；
- 构建流程文档化/脚本化，保证后续版本可复现；
- 不破坏 Linux 现有开发与打包流程。

## 4. 方案选型

| 方案 | 说明 | 取舍 |
|:--|:--|:--|
| A. Windows 实体机/虚拟机本地构建 | 在 Windows 环境装 Python + uv + PyInstaller，跑 spec | ✅ 推荐：最直接、可人工验证 GUI 行为；缺点是要备一台 Windows 环境 |
| B. GitHub Actions `windows-latest` CI 构建 | 提交触发，产物传 Artifacts | 适合长期自动发版，但首次调试远程 GUI 问题效率低；可作为二期 |

**推荐 A 起步，B 作为后续增强。** onefile vs onedir：选 **onedir**——启动快、杀毒误报率低；spec 已支持，不打 `REGUI_ONEFILE` 即可。

打包形态定为**便携 zip**（非安装器）：与「配置写 exe 同级目录」的现有机制自洽，规避安装器带来的权限问题。是否做 Inno Setup/NSIS 安装器列入范围外。

## 6. 回退预案

打包产物与脚本均为新增物，不动 `core/` 现有逻辑（T3/T5 若发现 Windows 专属缺陷需改代码，单项小改、逐项评审）。回退 = 删除新增脚本与产物，Linux 流程不受影响。

## 7. 明确不做（本期范围外）

- ❌ 不做安装器（Inno Setup/NSIS）、不做自动更新；
- ❌ 不做代码签名（需证书成本；未签名 SmartScreen 提示在分发说明中告知用户）；
- ❌ 不在包内置模型（交给模型下载计划；若用户改主意要内置，加一步拷贝 `models/` 即可）；
- ❌ 不做 32 位与 ARM 版 Windows；
- ❌ 本期不接 GitHub Actions（方案 B 另行立项）。

## 8. 风险与未确认项

- ⚠️ **UPX 杀毒误报**：Windows 上 PyInstaller + UPX 压缩的 exe 常被误杀。建议 T4 关闭 UPX（spec 中 `upx=False` 或环境变量控制），宁可包体大些；T5 在纯净机验证 Defender 表现；
- ⚠️ **Vulkan 依赖**：目标机显卡驱动须支持 Vulkan（近十年独显/核显基本都支持），老机器可能跑不动；分发说明中写明，缺模型引导阶段的错误提示也要覆盖「引擎起不来」的场景；
- ⚠️ **下载可达性**：首启下载模型走 GitHub，国内环境可能失败——前置计划已含手动放置兜底，分发说明需写清；
- 未确认：spec 中 `notifypy`、`qdarktheme` 数据收集在 Windows 构建机上的实际行为（T4 时验证）；Windows 版引擎的具体 release 版本选型（T2 时定，建议与模型清单同源的官方最新稳定版）。
